# Insites pOS Template Help Centre


## Overview
This module will add database driven pages to your website that are focused on support pages like FAQs and Articles and are fully responsive.


## Features
- FAQs 
- Articles
- Timeline
- Documentation


## Module Dependencies
- Insites Database v3.1.0^
- Insites Core v2.0.0^
- Insites Site Manager v1.6.0^
